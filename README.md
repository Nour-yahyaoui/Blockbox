BlockBox

BlockBox is a modern workflow automation platform designed to evolve from a portfolio project into a scalable, enterprise-grade SaaS.

Build workflows like:

Webhook → Condition → Transform → HTTP Request → Notification

✨ Features

- 🔗 Webhook-based workflows
- ⚙️ Visual workflow builder
- 🧩 Conditions, filters & transformations
- 🌐 HTTP/API integrations
- 🤖 Optional AI-powered workflows
- 📊 Execution history & logs
- ⚡ Real-time execution updates
- 🔐 OAuth authentication & secure sessions
- 🛡️ Rate limiting, SSRF protection & workspace isolation
- 📱 Responsive mobile-first interface

🏗️ Architecture

Next.js / Vercel
       ↓
Lightweight API & Frontend
       ↓
Rust / Actix Web / Render
       ↓
Workflow Execution Engine
       ↓
PostgreSQL + Redis

The architecture is designed to support multiple backend services, horizontal scaling, worker separation, and failover as BlockBox grows.

🛠️ Tech Stack

- Next.js + TypeScript
- React
- Rust + Actix Web
- PostgreSQL / Neon
- Redis
- OAuth
- WebSockets
- Vercel
- Render

🚀 Vision

BlockBox starts as a portfolio-grade implementation while maintaining the architecture needed to evolve into a real production SaaS platform.

Portfolio → MVP → Production SaaS → Enterprise Scale
